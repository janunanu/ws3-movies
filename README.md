# WS3 Movies App

A simple Node.js + Express application that fetches movie data from the OMDb API and displays the results in an HTML table.

---

## How to Run Locally

1. **Clone the repository**

```bash
git clone https://github.com/your-username/ws3-movies.git
cd ws3-movies

npm install

node movies.js

Open in http://localhost:5000/
```
